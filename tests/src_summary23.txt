HOMEPAGE=https://sourceforge.net/projects/pipestatus/
COMMENT=UNIX/POSIX shell helper for running pipes safely
MAINTAINER=cheusov@NetBSD.org
CATEGORIES=devel
LICENSE=public-domain
DESCRIPTION=pipestatus - source file for POSIX shell that allows
DESCRIPTION=to obtain an exit status of every program in a pipe.
DESCRIPTION=
DESCRIPTION=                        MOTIVATION
DESCRIPTION=
DESCRIPTION=When we program in shell we often run pipes like this
DESCRIPTION=
DESCRIPTION=    prog1 args1 | prog2 args2 | ... | progN argsN
DESCRIPTION=
DESCRIPTION=POSIX says that exit status of pipe is the exit status of LAST program
DESCRIPTION=in it, i.e.  progN in our example. That is, exit status of all other
DESCRIPTION=programs in pipe is silently ignored.  But in many situations exit
DESCRIPTION=status of all programs in pipe should be checked to make program
DESCRIPTION=robust. Some shells like BASH and ZSH have special extensions for
DESCRIPTION=doing this but POSIX shell unfortunately doesn't provide an EASY way
DESCRIPTION=for doing this.
DESCRIPTION=
DESCRIPTION=In order to solve the problem, described above pipestatus was written.
